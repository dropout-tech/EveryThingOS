# DropOut OS 外殼

琢奧識別的產品與作業系統介面。一百個產業包、一年 NT$100,000、免費顧問導入。

```bash
npm install
npm run dev
```

開啟 http://localhost:3000

| 路徑 | 內容 |
| --- | --- |
| `/` | 產品主張與四支柱 |
| `/industries` | 100 個產業包 |
| `/pricing` | 年費 |
| `/consulting` | 免費導入步驟 |
| `/saas` | 取代哪些雲端工具 |
| `/workspace` | 套皮 OS（可切產業包、黑白、海山湖） |
| `/workspace/reply` | 社群回覆（OpenReply 示範，Meta 未接） |
