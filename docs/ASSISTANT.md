# 問助理

老闆打一句話，例如「誰欠我們最多？」「明天要做什麼？」，馬上拿到用自己公司的帳算出來的答案：一句話、幾個關鍵數字、數字從哪來、一個帶你去那一頁的按鈕，再給兩三個接著問的問題。也能幫你寫好催款、追報價、回客人的訊息。

**數字只會從帳上來。** 規則決定「這是哪一類問題」，答案裡的每個數字都直接讀殼已經在用的資料；拿不到資料就直接說，並告訴你去哪裡處理。AI（有開的話）只能幫忙分類題目和改訊息的說法，碰不到數字。

## 在哪裡

- 選單「問助理」（`/workspace/ask`），每個人都有，不用開模組。
- 任何頁按 ⌘K／Ctrl+K 打一句話：看起來像問題（有「？」「誰」「多少」「嗎」…或比較長）時，第一個選項就是「問助理：…」；找不到頁面時它也會在最後。
- 網址 `/workspace/ask?q=誰欠我們最多` 直接問。
- 鍵盤：Enter 問、↑ 帶回上一題、Esc 清掉。手機上輸入框貼在畫面下方。對話存在這個瀏覽器分頁（`sessionStorage`），關掉分頁就清掉。

## 會回答什麼

程式在 `web/lib/assistant.ts`（純函式、沒有網路、同樣的資料同樣的答案）。

| 類型（intent） | 例句 | 讀哪份資料 |
| --- | --- | --- |
| `receivables` 誰欠錢 | 誰欠我們最多？ | 帳齡（收錢頁同一份） |
| `overdue` 逾期 | 逾期多少？拖最久的是誰？ | 帳齡 |
| `revenue` 營收 | 這個月營收多少？上個月呢？ | 本月銷項發票；上個月來自報表 |
| `revenue_compare` 比較 | 跟上個月比呢？ | 報表每月營收 |
| `margin` 毛利 | 毛利多少？上個月毛利？ | 報表毛利（ERPNext Gross Profit） |
| `low_stock` 快沒的貨 | 什麼貨快沒了？ | 報表「快不夠的貨」，沒有報表權限就用庫存頁 |
| `quotes` 報價 | 哪張報價卡住最久？ | 銷售頁的報價（開單日起算） |
| `orders` 訂單 | 有哪些訂單還沒出貨？這週要交的？ | 銷售頁的訂單（交期） |
| `leave` 請假 | 今天誰請假？這週呢？ | 人事頁 |
| `approvals` 假單 | 有假單等我核准嗎？ | 人事頁 |
| `payroll` 薪資 | 薪資跑到哪？ | 人事頁 |
| `agenda` 待辦 | 今天／明天／這週／下週要做什麼？ | 「今天」頁待辦＋有日期的報價、訂單、發票、進項發票、假單 |
| `customer` 某位客人 | 王美玲最近怎樣？大同欠多少？ | 客人資料、帳齡、單據、報表前十大、採購單據 |
| `top_customers` 大客人 | 最大的客人是誰？ | 報表前十大；沒有報表權限時只看最近的發票並標明 |
| `payables` 待付廠商 | 待付廠商多少？ | 應付帳款、進項發票 |
| `cash` 現金夠不夠 | 現金夠不夠撐？ | 現金與銀行科目 vs 30 天內到期的進項發票（沒有日期時用全部應付） |
| `purchases` 進貨 | 有哪些進貨還沒到？ | 採購單 |
| `leads` 在跟的客人 | 有哪些新客人在問？ | 客人頁 |
| `vat` 營業稅 | 營業稅大概多少？ | 本月銷項減進項稅額 |
| `einvoice` 電子發票 | 電子發票有沒有失敗？ | 收錢頁的電子發票 |
| `draft_reminder` | 幫我寫催款訊息（給王美玲） | 帳齡、逾期發票號碼與到期日 |
| `draft_quote` | 幫我寫報價追蹤 | 報價單號、金額、開單日、有效日 |
| `draft_reply` | 幫我回王美玲的問題 | 這位客人的訂單與發票 |
| `capabilities` | 你會什麼？ | — |

聽得懂：同義詞（營收／業績／營業額…）、全形半形（`ＮＴ$`、`？`）、常見簡體字、「今天／明天／這週／下週／這個月／上個月」、客人名字（全名、去掉「公司」「有限公司」、三個字的名字只打後兩個字）。

每個答案固定有：一句話、關鍵數字（`<Money>`，和其他頁同一個格式）、出處、連到那一頁的按鈕、兩三個接著問的問題（只列這個人答得了的）。示範模式的出處一律寫「示範資料」。

### 拿不到資料時

| 狀況 | 助理說什麼 | 帶你去 |
| --- | --- | --- |
| 公司沒開那個功能 | 這家公司沒有開「收錢」… | 那個模組的說明 |
| 職務看不到（選單沒有那頁、或 ERPNext 角色擋下某一段） | 你的職務看不到「收錢」…／你的 ERPNext 角色看不到帳齡 | 權限與職務說明 |
| 報表（比較、毛利、前十大） | 報表只有老闆、主管、會計看得到 | 權限與職務說明 |
| ERPNext 連不上 | 現在拿不到 ERPNext 的資料：…不會改用示範數字 | 設定 › 連線狀態 |
| 登入過期 | 登入過期了 | 重新登入 |
| 人事模組沒裝 | 還沒裝人事模組 | 人事說明 |

只缺一部分時照樣回答，並說明哪些沒算進去（例如客人狀況裡「你看不到帳款，所以沒算進來」）。

## 資料與權限

`web/lib/assistant-server.ts` 在伺服器組出 `AssistantFacts`，交給頁面：

- 只讀這個人選單裡有的模組（`featuresFor(shop.modules, roles)`），報表照 `canSeeReports`。沒權限的部分根本不會送到瀏覽器。
- 讀取都是現有的：`dropout_core.shell.books`、`dropout_core.shell.people`、`dropout_hr_tw.shell.today`、`dropout_core.reports.overview`，以登入者本人的 ERPNext 身分，所以 ERPNext 的角色與使用者權限會再擋一次。`books` 回來的 `denied`（例如 `cash`、`ar_aging`、`Quotation`）會變成「看不到」，不會當成 0。
- `dropout_core.shell.books` 這次多回傳報價、訂單、發票的 `date`／`due` 與進項發票的 `due`，給「卡最久」「這週」用。舊站台沒有這兩個欄位時，助理會說「沒有日期」而不是猜。
- 練習模式：用和其他頁同一份練習帳本，加上瀏覽器分頁裡的修改（在收錢頁按了收款，問助理就會少一筆）；練習帳本沒有日期，所以替每張單據配上固定的示範日期。

## AI（選用）

沒有 AI 也完整可用。公司接上 glue（`GLUE_URL`＋`SHELL_TOKEN` 或 `GLUE_ADMIN_TOKEN`），而且 glue 有 `AI` binding 時才會用到：

| 什麼時候 | 送出什麼 | AI 回什麼 | 怎麼驗 |
| --- | --- | --- | --- |
| 規則聽不懂一個問題 | 只有那一句問題（最多 200 字） | 一行 JSON：`intent`、`period`、`name` | `intent`、`period` 必須在清單裡；`name` 必須是問題裡原本就有的字，而且之後還要對得上帳上的名字；其他一律當「聽不懂」 |
| 按「讓 AI 潤一下」 | 那則草稿，加上草稿裡已經寫的事實（名字、金額、日期、單號） | 改過說法的草稿 | 出現任何原本沒有的數字（含國字數字）、漏掉任何一個事實、加了連結、太短或太長，都作廢並保留原稿 |

- 路徑：瀏覽器 → `POST /api/assist`（同源檢查、登入檢查、格式檢查）→ glue `POST /admin/tenants/:site/assist`（只有 `ADMIN_TOKEN` 或 `SHELL_TOKEN` 可用，站台要存在）→ Workers AI。程式在 `glue/src/assist.ts`，測試在 `glue/test/assist.test.ts`。
- 模型：`ASSIST_MODEL`，沒設就用 `SUMMARY_MODEL`（預設 `@cf/meta/llama-3.3-70b-instruct-fp8-fast`）；有設 `AI_GATEWAY` 會經過 AI Gateway。**AI Gateway 的請求紀錄預設會存下提示內容，若不想保留問題與草稿，請在那個 Gateway 關掉 logging。**
- glue 不寫資料庫、不記錄問題或草稿內容。Cloudflare 不拿 Workers AI 的輸入訓練模型。
- 沒有 AI binding 回 `501 {available:false}`，殼就停用 AI 按鈕，只用規則。

## 還沒做的

- 沒有每天的營收（只到月）；沒有「去年同期」。
- 「明天以後才開始、已經核准」的假單，人事的讀取還沒提供，助理會說要到人事看。
- 現金夠不夠只比現金與要付廠商的錢，沒有算薪水、房租、貸款。
- 庫存數量是 0 的品項只在報表的「快不夠的貨」裡；沒有報表權限時看不到。
- 對話（Chatwoot）沒有預填訊息的網址，所以是「複製並打開對話」，到收件匣貼上。
- 練習模式的人事資料和人事頁的示範是兩份相同的程式（`assistant-server.ts` 的 `practiceHr` 與 `app/workspace/hr/page.tsx` 的 `demo`），改一邊要改另一邊。
