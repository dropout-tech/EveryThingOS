# 人事薪資

人事是最多人每天都會碰的模組：員工打卡、請假、主管核准、月底發薪。這份寫的是 DropOut OS 的人事包含什麼、每年一定要核對什麼、還沒做的有哪些。

**費率與分級表每年都會變。系統裡的預設值只是起點，不是官方數字。第一次發薪前，以及每年一月，一定要對照官方公告核對一次。**

## 用什麼做

- **Frappe HRMS**（[github.com/frappe/hrms](https://github.com/frappe/hrms)，`version-15` 分支，GPLv3）：員工資料、假別與假單、打卡、排班、薪資結構、薪資單、薪資發放，全部用上游的。
- **`dropout_hr_tw`**（`frappe-apps/dropout_hr_tw`）：台灣的設定，裝在 HRMS 上面。不改 HRMS 原始碼。
- `dropout_core` 不依賴 HRMS。沒選「人事」的公司不會裝 HRMS。

開站時，殼裡選了「人事」模組（2 人以上的公司預設會勾），導入工具就會裝 `hrms` 與 `dropout_hr_tw`。不要可以取消勾選。

## 裝好之後有什麼

| 東西 | 在哪裡 | 說明 |
| --- | --- | --- |
| 薪資元件 | 本薪、伙食津貼、加班費、勞保自付額、健保自付額、勞退自提、所得稅扣繳 | 公式只讀費率設定，不寫死數字 |
| 費率設定 | ERPNext「Taiwan Payroll Settings」 | 當年度的基本工資、勞保、就保、健保、勞退、扣繳、伙食津貼免稅額度、投保薪資分級表 |
| 假別 | 特休、病假、事假、婚假、喪假、產假、陪產假、生理假、家庭照顧假 | 天數、給不給薪都可以改 |
| 薪資結構範本 | 「台灣月薪範本 - 公司縮寫」（草稿） | 人資檢查、送出後，再指派給員工並填本薪 |
| 員工資料欄位 | 員工資料最下面「台灣勞健保與勞退」 | 投保薪資（空白就套分級表）、健保眷屬人數、勞退自提比例、不參加就業保險 |
| 職務「人資」 | 團隊頁 | HR Manager、HR User、Leave Approver、Employee |
| 殼的人事頁 | `/workspace/hr` | 我打卡、今天誰請假、等我核准的假單、這個月薪資進度 |

第一次安裝時，會替原有的「老闆」補上 HR 角色（看得到薪資）、替「主管」補上請假核准。之後公司自己改職務，系統不會再改回來。

所有東西都是「沒有才建」：公司改過的假別、薪資元件、費率，重跑 `bench migrate` 都不會被蓋掉。

## 薪資怎麼算

每張薪資單在計算前，系統會把當年度費率和這位員工的投保薪資抄到薪資單的「台灣扣繳基準」區塊，薪資元件的公式只讀那裡的數字。所以改了費率設定，下一張薪資單就照新的算；已經確認的薪資單不會變。

| 項目 | 怎麼算 |
| --- | --- |
| 本薪 | 薪資結構指派的「基本」金額，依出勤天數比例 |
| 伙食津貼 | 費率設定裡的免稅額度。超過額度的部分要另外併入薪資課稅 |
| 加班費 | 用「額外薪資」逐月登打，系統不自動算時數 |
| 勞保自付額 | 勞保投保薪資 ×（普通事故費率＋就業保險費率）× 勞工負擔比例，元以下四捨五入 |
| 健保自付額 | 健保投保金額 × 健保費率 × 被保險人負擔比例，四捨五入後 ×（本人＋眷屬，眷屬有計費上限） |
| 勞退自提 | 月提繳工資 × 員工自己選的自提比例（不超過上限） |
| 所得稅扣繳 | 本薪達到「每月起扣金額」時 × 扣繳率；起扣金額空白就不扣 |

投保薪資：員工資料有填就用員工資料；沒填就拿薪資結構指派的基本金額，套分級表裡「大於或等於這個金額的最低一級」，超過最高級就用最高級。有固定津貼要算進投保薪資的，請直接在員工資料填。

薪資單也會估雇主負擔的勞保、健保（要填平均眷口數）與 6% 勞退，方便看人事成本；職業災害保險費率依行業別，沒有計算。

## 每年一定要核對的數字

到 ERPNext 打開「Taiwan Payroll Settings」，對照下面的官方來源改好，再勾「已對照官方公告核對」。換年度或改了任何費率，這個勾會自動取消；殼的人事頁在還沒核對時會提醒。

| 欄位 | 預設值 | 對照哪裡 | 狀態 |
| --- | --- | --- | --- |
| 基本工資（月／時） | 29,500／196 | 勞動部基本工資公告 | 預設是 2026 年的公告值，**要核對** |
| 伙食津貼免稅額度 | 3,000 | 財政部 | 2024 年起的額度，**要核對** |
| 勞保普通事故保險費率 | 11.5% | 勞動部勞工保險局 | 這是 2024 年的費率；依勞工保險條例會逐年調整，**一定要改成當年度的** |
| 就業保險費率 | 1% | 勞動部勞工保險局 | **要核對** |
| 勞保負擔比例（勞工／雇主） | 20%／70% | 勞動部勞工保險局 | 一般受僱勞工的比例，**要核對** |
| 健保費率 | 5.17% | 衛生福利部中央健康保險署 | **要核對** |
| 健保負擔比例（被保險人／投保單位） | 30%／60% | 衛生福利部中央健康保險署 | 一般受僱者的比例，**要核對** |
| 眷屬計費上限 | 3 口 | 衛生福利部中央健康保險署 | **要核對** |
| 投保單位平均眷口數 | 空白 | 衛生福利部中央健康保險署 | 只用來估雇主負擔，每年公告，**沒有預設** |
| 勞退雇主提繳率 | 6% | 勞工退休金條例（不得低於 6%） | 公司提繳更高可以改 |
| 勞退自提上限 | 6% | 勞工退休金條例 | **要核對** |
| 扣繳率 | 5% | 財政部各類所得扣繳率標準 | 適用「按全月給付總額扣取 5%」的做法，**要核對** |
| 每月起扣金額 | 空白 | 財政部當年度薪資所得扣繳稅額表 | **沒有預設**，空白就不扣，請填當年度的數字 |
| 投保薪資分級表 | 29,500 起到 219,500 | 勞保局「勞工保險投保薪資分級表」、「勞工退休金月提繳分級表」，健保署「投保金額分級表」 | 預設只放了基本工資以上的級距，**每一級都要對照**；有部分工時人員要自己補基本工資以下的級距 |

除了這張表，假別的天數也要對照當年度的勞動基準法、勞工請假規則、性別平等工作法。特休天數依年資，要用 HRMS 的「假別分配」給每個人。

## 還沒做的

- **扣繳憑單申報、各類所得申報**：沒有產生申報檔，年底請用財政部的申報系統或會計師。
- **勞保、健保、勞退的加退保與異動申報**：沒有接勞保局 e 化服務系統或健保署，加保、退保、調薪異動要自己去申報。
- **所得稅扣繳**只看本薪；獎金、超過免稅額度的伙食津貼與加班費、兼職所得，要人工調整。也還沒有「薪資所得扣繳稅額表」查表扣繳。
- **加班費**不從打卡自動算，用額外薪資登打；勞動基準法的加班費率與每月 46 小時免稅上限，人資要自己把關。
- **月中到職、離職**的勞健保按日計算還沒做，系統以整月計。
- 二代健保補充保費、職業災害保險、雇主的健保與勞保負擔入帳，都還沒做。
- 殼的打卡沒有帶 GPS 位置。公司在 HR Settings 打開「位置追蹤」的話，請員工改用 HRMS 的手機頁面打卡。
- 員工要先由人資在 ERPNext 建立員工資料，並在「使用者帳號」欄位連到他的登入帳號，才能在殼裡打卡。

## 測試

`frappe-apps/dropout_hr_tw/dropout_hr_tw/tests/` 有：重跑設定不會重複也不會蓋掉公司改過的、改費率之後薪資單跟著變、員工資料的投保薪資優先、只有被指定的核准人或人資能核准、不能核准自己的假單、只能替自己打卡。CI 的 ERPNext 工作會裝 HRMS 並跑這些測試。
