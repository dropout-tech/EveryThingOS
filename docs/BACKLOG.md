# 還沒接上的事

帳留在 ERPNext。不搬到 InsForge。稅額以單據上的數字為準，不由模型補 5%。

## 程式已經接上

- 生意頁可以搜單號、客人、品名。
- 訂單顯示還差幾件。出貨若會低於安全量，ERPNext 會拒絕。
- 超過信用額度時，開報價和轉成訂單會被 ERPNext 拒絕，訊息是「超過信用額度」。
- 收訂金、部分出貨、退回原出貨單都有 API。真的帳套裡，未完成的訂單會出現「收訂金」「出這次」；已有出貨單才出現「退這次」。三個都是次要按鈕。
- 稅額是 0、數量大於 0、而且這張單還沒收過款時，才印前餘、本筆、後餘、稅額 0。已付款或只收了一部分的發票不印，避免把已收的錢再加一次。
- 本月銷貨若真的讀到總帳收入科目，標籤是「本月銷貨（未稅，總帳）」。讀不到時維持「本月銷貨（未稅）」。練習帳本的數字不是總帳，所以不加「總帳」兩個字。
- 進階版右側代理人：一句話先變成待確認的動作，員工按「就這樣做」才寫進 ERPNext。模型沒接上時直接說還沒接上，不假裝已經開單。允許的動作只有開報價、往下走、收訂金、部分出貨、退回原單。

## 還差資料，所以畫面先不掛

- 開報價的表單沒有這位客人的額度與未收金額，所以不先顯示「超過信用額度」。送出時仍由 ERPNext 擋下。
- 收錢頁的分錄本來就能點回傳票。不再另外做一層連結。
- 三家示範公司的報價、訂單、發票都已走完並收款，不會出現在「還沒做完」的那一欄，所以那三張單上看不到訂金與出貨按鈕。

## 要你本人做

這些沒有帳號或主機，程式接不上，也不能用假的對話或假的會議紀錄代替。

- LINE 官方帳號，並在 Chatwoot 接上這個頻道。
- Instagram／Meta 的頻道。
- 一台 Vexa，加上日曆，並讓機器人真的進過一場 Zoom、Google Meet 或 Teams。
- DropOut 自己的 Cloudflare 帳號：建立 D1、Queues、Workers AI，部署膠水，並在 Vercel 專案 `dropout-os` 設定 `GLUE_URL` 與 `SHELL_TOKEN`（或管理用權杖）。這次環境接上的是別的 Cloudflare 帳號，不能部署過去。
- 一台對外的 ERPNext，並在同一個 Vercel 專案設定 `ERPNEXT_URL`。這台電腦上的 ERPNext 只聽 `127.0.0.1:8080`，公開網站連不到。
- 要開右側代理人的店，在店的資料把 `agent` 寫成 `advanced`。導入流程不會自己打開。練習時可以在 `dropout_shop` 這個 cookie 寫上同樣的值來看面板；沒有模型時，它只會說還沒接上。
- 若要開 pull request，這個身分要先成為 GitHub 協作者。程式已經推上分支 `cursor/live-erp-cycle-35c1`。

## 決定不做

- 不把進銷存換成 InsForge。
- 不由模型自己加 5% 稅。
