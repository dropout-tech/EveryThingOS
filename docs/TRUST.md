# 信任文件：條款、個資、SLA、資安

企業採購與法務會要的五份文件，都在官網上。內容全部寫在 `web/lib/legal.ts`，五頁共用 `web/components/LegalPage.tsx`；年費從 `web/lib/commercial.ts` 讀，不另外寫死。每頁上方都標「草稿，簽約前請由律師審閱」與版本日期（`LEGAL_VERSION`）。

| 頁面 | 寫什麼 |
| --- | --- |
| `/terms` 服務條款 | 誰跟誰簽、服務內容、年費與付款、試用、到期與寬限、暫停與終止、資料歸屬與解約後處理、客戶責任、開源授權、責任上限、保密、準據法 |
| `/privacy` 隱私權政策 | 依個資法第 8 條告知：DropOut 自己蒐集的個資（官網訪客、客戶聯絡人、系統使用者、Cookie）、特定目的代號、期間地區對象方式、第 3 條五項權利、回覆期限 |
| `/dpa` 資料處理附約 | 客戶是委託機關、DropOut 是受託者（個資法第 4 條、施行細則第 8 條）；處理範圍、複委託廠商清單、事故通知、監督、跨境、結束時刪除 |
| `/sla` 服務水準 | 月可用率 99.5%、RPO 24 小時、RTO 8 小時、嚴重事故 2 小時回應、支援時段、維護預告 72 小時、抵扣 5%／10%／25%（上限 25%）、排除項目 |
| `/security` 資安說明 | 只寫程式裡真的有的：ERPNext 登入與 PKCE、session 綁公司、兩步驟、密碼政策、輸錯 5 次鎖住、閒置登出、職務、Activity Log／Version／Access Log、一公司一站、金鑰加密、Tunnel、Cloudflare Access、驗簽、每日備份到 R2；也寫出還沒有的認證 |

## 要填的資料：都在一個地方

`web/lib/legal.ts` 的 `ENTITY`。沒填的值在頁面上以橘色「【待填：…】」顯示。

| 欄位 | 內容 |
| --- | --- |
| `name` | 公司登記全名 |
| `taxId` | 統一編號 |
| `address` | 登記地址 |
| `representative` | 代表人 |
| `email` | 一般聯絡信箱，沿用 `COMMERCIAL.email` |
| `privacyEmail` | 個資聯絡信箱 |
| `phone` | 客服電話 |
| `court` | 合意管轄法院 |
| `host` | 主機商名稱與機房地區 |
| `speechToText` | 會議轉文字服務；自架 Whisper 就刪掉 DPA 那一列 |
| `paymentDays` | 付款期限 |
| `monitor` | 可用率監測工具 |
| `backupRetention` | R2 備份保存天數 |

## 律師要看的

- 責任上限（12 個月已付費用）、故意重大過失除外的寫法。
- 終止條件、30 天改善期、不續約通知期，以及退費。
- 個資特定目的代號與類別代號是否選對；行銷用途的同意方式。
- DPA 是否完整涵蓋施行細則第 8 條各款；72 小時事故通知是否做得到。
- 跨境傳輸（Cloudflare、Resend、Vercel 在美國）的告知寫法。
- 解約後 90 天刪除站台與備份，對客戶的法定保存義務（商業會計法）是否需要再提醒或延長。

## 會計師要看的

- 年費「未稅」的發票開立方式、付款期限。
- 服務抵扣是折讓還是下期扣抵，發票怎麼開。

## 老闆要決定或確認的

- 嚴重事故「2 小時內回應、不分時段」要有人輪值才做得到。
- 「每月還原一次到測試站」「人員簽保密約定」寫進文件就是承諾，要真的做。
- 兩步驟、密碼政策、鎖帳號、閒置登出目前是老闆在團隊頁自己打開，開站時不會自動打開。要不要改成預設打開。
- 解約後 90 天刪站與刪備份目前是營運手動做，程式沒有自動刪除。
- 文件上的數字要跟程式一致：試用 30 天、快到期 60 天、寬限 14 天在 `glue/src/accounts.ts` 與導入工具；改一邊要改另一邊（`web/lib/legal.ts` 的 `CONTRACT`）。
- 換寄信服務、主機商、金流或加值中心時，更新 DPA 的廠商表並在 30 天前通知客戶。
