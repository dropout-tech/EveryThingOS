# 專案與工時

專案頁在 `/workspace/projects`，選單叫「專案」。給接案、顧問、設計、裝潢工地這類「一案一案做」的公司：每一案賺不賺、做到哪、還有多少工時沒跟客人收錢，一頁看完；工時用手機記，做完的工時一鍵開成發票。

資料全部在 ERPNext 的專案（Project）、工作項目（Task）、工時表（Timesheet）。這一頁不另外存資料。

## 誰能做什麼

| 能做的事 | ERPNext 角色 |
| --- | --- |
| 看專案 | 能在 ERPNext 讀專案（Project）的人。讀不到時整頁顯示「你的 ERPNext 角色看不到專案」 |
| 記工時 | System Manager、Projects User、Projects Manager、HR User、Accounts User、Manufacturing User |
| 加工作項目、換欄位 | System Manager、Projects User、Projects Manager |
| 開成發票 | System Manager、Accounts User、Accounts Manager |

按鈕照角色顯示，但真正擋人的是 ERPNext：每一個動作都在伺服器再檢查一次登入、同站來源、「暫停寫入」開關，然後由 ERPNext 照它自己的權限決定。某一段（工作項目、工時、工作類型、服務品項）讀不到時，只有那一段寫「你的 ERPNext 角色看不到」，其他照常。

## 每個數字是什麼

| 畫面上 | 意思 | ERPNext 從哪裡來 |
| --- | --- | --- |
| 合約金額 | 這個專案的業務訂單金額 | Project `total_sales_amount`（送出的業務訂單掛這個專案就會算進來） |
| 到目前的成本 | 工時成本＋採購＋領料 | 工時 × 成本費率（Timesheet Detail `costing_amount`），加上 Project `total_purchase_cost`、`total_consumed_material_cost` |
| 已請款 | 已送出的銷項發票 | Project `total_billed_amount` |
| 做了還沒請款 | 可以請款、還沒開發票的工時金額與時數 | 已送出、勾「可請款」、還沒掛發票的工時（跟發票上「抓工時」按鈕同一個條件） |
| 毛利 | （合約金額 − 成本）÷ 合約金額。沒有合約金額時，用已請款＋還沒請款的金額當分母 | 同上 |
| 預算用了 | 成本 ÷ 預估成本。沒填預估成本時除以合約金額 | Project `estimated_costing` |
| 進度 | 完成的工作項目 ÷ 全部工作項目；沒有工作項目時用專案上的完成度 | Task `status`、Project `percent_complete` |
| 截止 | 專案預計完成日 | Project `expected_end_date` |

### 顏色

| 標籤 | 條件 |
| --- | --- |
| 超支 | 預算用了超過 100%，或毛利是負的 |
| 要注意 | 過了截止日還沒完成、預算用掉的比例比進度快 15 個百分點以上，或毛利不到 15% |
| 順 | 其他 |

上面四格：進行中幾案（含幾案超支、要注意）、本月工時、做了還沒請款（未稅）、進行中案子的平均毛利。清單可以依「最需要注意」、截止日、毛利、還沒請款、合約金額排序，也可以只看進行中、要注意或全部。

## 記工時

手機上按「記工時」會從下面滑出一張表：專案、工作項目（可不選）、幾小時、日期、做什麼（工作類型）、備註、可不可以跟客人請款。

規則在畫面和伺服器各檢查一次，以伺服器為準：

- 以 0.25 小時（15 分鐘）為單位，一筆 0.25 到 12 小時
- 同一個人一天加起來最多 16 小時
- 日期預設今天（台北時間），不能記未來，最多補登 60 天內
- 專案要存在、你讀得到、還沒完成或取消；選的工作項目要屬於這個專案

伺服器方法是 `dropout_core.projects.log_time`。它找出登入者的員工資料（Employee 的「使用者帳號」），從早上 8 點起接在他那天最後一筆工時後面排時間，所以不會跟 ERPNext 的「時間重疊」檢查打架；排到超過午夜就不收。工時表建好就送出，這樣才能請款，費率照 ERPNext 的工作類型（Activity Type）或工作費率（Activity Cost）。

## 開成發票

在專案裡按「開成發票」：

1. 列出這個專案還沒請款的工時，預設全選，這次不收的取消勾選
2. 下面先算給你看：每一種工作幾小時 × 單價、未稅、營業稅 5%、含稅
3. 按「開成發票」

伺服器方法是 `dropout_core.projects.make_invoice`。它用 ERPNext 自己的 `get_projectwise_timesheet_data` 再查一次哪些工時真的還能請款（已送出、可請款、還沒掛發票、不在別張發票草稿上），再用 `make_sales_invoice` 開一張**銷項發票草稿**，工時掛在發票的工時表上，每一種工作一行。會計在 ERPNext 確認稅別後送出，才會開出電子發票，那些工時也才會變成「已請款」。

需要：

- 專案要填客人
- ERPNext 裡要有一個「不管庫存」的銷售品項（例如「專業服務」），有好幾個時可以在畫面上選
- 按的人要能在 ERPNext 建銷項發票

畫面上的 5% 是預覽；發票上的稅額以 ERPNext 的稅別範本為準。

## 工作項目

每一案的工作項目分成待辦、進行中、完成三欄（ERPNext 的 Open、Working、Completed；Pending Review 放在進行中，Overdue 放在待辦）。按卡片上的按鈕換欄位，手機上三欄上下排。新增工作項目用 `frappe.client.insert`，換欄位用 `frappe.client.set_value`；有前置工作還沒完成時 ERPNext 不讓你改成完成，畫面會顯示 ERPNext 的原因。

## 示範模式

沒接 ERPNext 時是示範資料，頁面標「示範資料」，依現場換一套：

- 接案／顧問：品牌顧問、官網改版、年度維運（已超支）、季度社群代操
- 工地／裝潢：全室裝修、店面翻修、浴室防水
- 其他現場：三個通用的案子

示範模式記的工時、換的欄位、開的發票只存在這個瀏覽器。開的發票會出現在「生意」頁的「請他付錢」那一欄。

## 出錯時

- ERPNext 連不上：整頁顯示連線錯誤，不會改用示範數字
- 「暫停寫入」打開時：按下去會顯示暫停寫入的說明，不會寫進 ERPNext
- 工時超過 2,000 筆：只算最近的 2,000 筆，畫面會提醒到 ERPNext 看完整報表；專案一次最多 100 案

## 還沒做的

- 在這裡開新專案、改合約金額或預估成本（請在 ERPNext 的專案與業務訂單改）
- 依里程碑或完工比例請款（目前只有依工時）
- 工時表草稿的審核流程（這裡記的工時直接送出）
