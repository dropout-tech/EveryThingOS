# 客戶入口：線上看報價、簽名接受、看發票付款

業務在 `/workspace/portal`（選單「客戶入口」）或銷售看板卡片上的「傳給客人」，就能把報價單、訂單、發票做成一條連結，複製或用 LINE 傳給客人。客人打開連結不用註冊、不用登入，看得到單子內容，報價可以直接打名字、簽名接受，發票可以下載 PDF、線上付款或看匯款帳號。

## 客人看到什麼

連結長這樣：`https://你的網址/q/<一串亂碼>`。頁面沒有選單、不會被搜尋引擎收錄，也不會把網址透露給下一個網站。

| 區塊 | 內容 |
| --- | --- |
| 抬頭 | 公司名稱、標誌（ERPNext 公司的 Logo）、單號、日期、有效期限或付款期限 |
| 品項 | 品名、數量、單價、小計 |
| 金額 | 未稅、營業稅 5%（稅率不是 5% 時寫實際稅名）、含稅總額 |
| 條款 | 單子上的「Terms」 |
| 聯絡 | 負責業務的名字、電話、Email |
| 報價 | 「接受報價」：打全名（必填）、可以另外手寫簽名、勾同意 → 看到確認畫面和收據，可以列印 |
| 發票 | 「下載 PDF」（ERPNext 的列印格式）、「線上付款」（有接綠界／藍新才會出現）、匯款帳號（ERPNext 公司銀行帳戶） |

連結過期、被撤回、或單子已經取消時，客人只會看到一句說明和業務的聯絡方式，看不到金額。

LINE、Facebook 等聊天軟體產生預覽時，只會拿到「有一份文件給你」的通用卡片，不會讀到金額，也不會算成客人看過。

## 業務看到什麼

`/workspace/portal` 列出所有連結和狀態：已寄出、看過 N 次、已簽、過期、已撤回。每條可以：

- 複製連結、用 LINE 分享（`https://line.me/R/share?text=`）
- 改有效期限（3、7、14、30、60、90 天，預設 14 天）
- 撤回：馬上失效，客人再打開只會看到「這個連結已經停用」

客人簽了之後，ERPNext 的報價單上會多一段「線上接受」：簽名人、時間、簽名圖檔、哪一條連結、來源位置的雜湊值，評論區也會留一筆紀錄。

## 安全設計

- **連結是簽過名的**：內容用 HMAC-SHA256 簽章，金鑰從 `PORTAL_SECRET` 依每個公司（ERPNext 站台）各自推導，A 公司的連結不可能打開 B 公司的單子。驗證用固定時間比對，連結裡寫死到期時間。
- **金鑰不會到瀏覽器**：簽章和驗證都在伺服器端。`PORTAL_SECRET` 至少 32 個字元，沒設定時客戶入口會顯示「還沒設定」，不會產生連結。
- **客人碰不到 ERPNext**：客人的每個動作都經過 DropOut 膠水服務，再用公司的整合帳號呼叫 `dropout_core.portal` 的三個方法。客人沒有任何 ERPNext 帳號或 API 金鑰。
- **建立連結要有權限**：業務建立連結時，先用他自己的 ERPNext 身分讀那張單子；讀不到就不能分享。只能分享已送出的單子。
- **可以撤回**：每條連結都記在膠水服務的 D1 資料庫（`portal_links`），撤回、過期都以資料庫為準，就算連結的簽章還有效也打不開。
- **防亂試**：接受報價每條連結 15 分鐘內最多試 5 次，網站端每個來源 10 分鐘內最多 20 次。已經接受過的報價再送一次只會回「已接受」。
- **不存原始 IP**：只存加了公司金鑰的雜湊值，夠用來比對是不是同一個來源，看不出真實位置。
- **簽名檢查**：只收 PNG、最大 300 KB，存成 ERPNext 的私人檔案。
- **付款網址**：只接受 ERPNext 付款請求產生的 http(s) 網址。

### 示範模式

沒有接 ERPNext 時，連結裡直接放單子內容，用公開的示範金鑰簽（畫面上一定有「示範」橫幅）。公司名稱、聯絡人、匯款帳號固定寫「示範公司／示範銀行」，避免有人拿示範連結冒充真的公司騙匯款。正式接上 ERPNext 後，示範連結一律打不開。看過次數、簽名、撤回只記在同一個瀏覽器裡。

## 要怎麼開

| 項目 | 設定 |
| --- | --- |
| 網站（web/） | 環境變數 `PORTAL_SECRET`（至少 32 個字元的亂數，例如 `openssl rand -base64 48`），以及原本的 `GLUE_URL` |
| 膠水服務（glue/） | 套用 D1 migration `0008_portal_links.sql` |
| ERPNext | 更新 `dropout_core`（`bench migrate`），報價單會多出「線上接受」欄位 |
| 線上付款 | 安裝並啟用 `dropout_pay_tw`（綠界或藍新、幣別 TWD）；沒有的話只顯示匯款帳號 |
| 匯款帳號 | ERPNext「Bank Account」勾「Is Company Account」 |

換掉 `PORTAL_SECRET` 會讓所有已經寄出的連結失效。

### 技術介面

| 位置 | 介面 |
| --- | --- |
| ERPNext | `dropout_core.portal.document`（讀單子，照登入者權限）、`dropout_core.portal.accept_quotation`（POST，只給整合帳號）、`dropout_core.portal.payment_link`（POST，只給整合帳號，用 ERPNext 的 `make_payment_request`） |
| 膠水服務 | `/admin/tenants/:site/portal-links`：列表、建立、`/:id`、`/:id/revoke`、`/:id/expiry`、`/:id/open`、`/:id/accept`、`/:id/pay`、`/:id/pdf`（轉送 `frappe.utils.print_format.download_pdf`） |
| 網站 | `/q/[token]`、`/q/[token]/pdf`、`/api/portal/links`、`/api/portal/links/[id]`、`/api/portal/accept`、`/api/portal/pay` |

## 法律上的提醒

線上打名字加勾選同意，在台灣一般可以當作「電子簽章」（電子簽章法第 4、9 條），我們也留下時間、連結、來源雜湊和簽名圖檔當紀錄。但它不是憑證機構簽發的「數位簽章」，金額大、條款複雜或對方是政府機關時，證明力可能不夠。正式使用前，請找律師看過你的報價條款、同意文字，以及這種接受方式在你的行業是否足夠。
