# Open Chat

Open Chat 是一個收件匣：LINE 官方帳號、IG 私訊、FB 粉專、官網小工具。人回的訊息用 Chatwoot。殼只帶員工進去，不重做整套收件匣。

這不是 LINE 社群的 OpenChat。LINE 群組沒有官方 API，這版不讀、不回。

## 員工看到什麼

頁面在「對話」（`/workspace/chat`）。

收件匣接上之後，最上面是「去收件匣回訊息」。用已經登入的帳號打開 Chatwoot，不用再打一次密碼。新對話找到或建立客人，記在客人的時間軸上。貼圖、附件、指派留在 Chatwoot。

還沒接上時，最上面是等最久的那個人。按「回她」只寫在這台電腦，畫面要寫明還沒傳到 LINE、IG 或 FB。旁邊是這個人的卡片：跟到哪、買過什麼、還欠什麼。「附報價」去生意，「標成同一個人」只在信箱或手機相同時成立。下面「留言自動轉私訊」是 ManyChat 留下的那一件工作。

同一個人只認驗證過的信箱或手機。姓名一樣不合併。

## 取代哪一套

| 員工原來要開的 | Open Chat 裡的哪一塊 |
| --- | --- |
| LINE 官方帳號後台 | LINE 官方帳號，一對一 |
| Instagram 收件匣 | IG 私訊 |
| Facebook 收件匣 | FB 粉專私訊 |
| 官網右下角聊天客服 | 官網小工具 |
| ManyChat | 只有留言關鍵字 → 私訊 |

人回的四個通道進同一個 Chatwoot。ManyChat 那件工作只留：留言出現關鍵字才私訊，公開回一句。客人回了之後，對話仍由 Chatwoot 接手。

## 這版不做

- LINE 社群、LINE 群組
- 殼裡的完整收件匣（貼圖、指派台）
- ManyChat 的流程畫布、廣播、點數
- LINE 群發
- 用姓名把兩個人併成一個
- 把練習回覆說成已經送出

Meta（IG、FB）：客人最後一則之後 24 小時內可以回。超過的，這裡不代送。LINE 用回覆 token 回，不吃方案額度。這版沒有主動推播。

## 程式在哪

| 路徑 | 內容 |
| --- | --- |
| `web/app/workspace/chat` | 員工的對話頁 |
| `web/components/open-chat` | 一個收件匣取代哪些後台 |
| `web/lib/open-chat` | 通道、同一個人、24 小時與回覆 token |
| `web/lib/reply.ts` | 關鍵字對留言、練習用的收件匣 |
